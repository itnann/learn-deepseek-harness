# 课程使用说明

这条主线不是源码导读，而是一组连续实验。每章目录里都有 `README.md` 和 `code.py`：先读“问题”，猜一猜你会怎样改，再运行代码观察结果。

```sh
python course/s01_one_loop/code.py
```

所有示例都使用内存数据和确定性的 `ScriptedModel`。看到 `MODEL` 行，表示模型提出下一步；看到 `HARNESS` 行，表示运行框架正在执行、拦截或记录；看到 `TOOL` 行，表示能力产生了结果。

## 一条贯穿全课的原则

```text
不要因为大项目有某个抽象，就在小项目里照搬它。
先让问题真实出现，再用本章机制消除它。
```
